# 桌面引力 Desktop Gravity

把 Mac 桌面变成一个投篮场。按下 Control + Option + G，桌面图标的副本会从原位掉落。抓起文件夹，朝篮筐甩出去；投偏飞出篮板那一侧，还会有一个场外回传。

[下载最新版](https://github.com/zldfv/desktop-gravity/releases/latest)

## 试玩

适用于 Apple 芯片的 Mac，最低系统要求为 macOS 13。打开 DMG，将「桌面引力」拖入「应用程序」，启动后从菜单栏选择「用临时图标投篮」即可试玩。使用真实桌面图标时，按提示允许读取 Finder 坐标，游戏只移动图标副本。

直投得 2 分，打板得 3 分。先得 10 分完成一局。R 开新局，Esc 回到桌面。

当前 1.2 为试玩版，使用本机临时签名，未做 Apple 公证。macOS 可能在首次打开时拦截。
